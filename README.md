## Description

Write the funniest one-line patch note for a bug in real life or human biology, 160 characters max. Free entry, open 72 hours, and the top 5 places split the reward pool equally. main.py writes the chosen line to /output/entry.txt.

The chosen line:

> v2.3.5: fixed a bug where walking through a doorway cleared the short-term memory cache.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes a single line to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set, falling back to `/output/entry.txt`). The program is deterministic: every run writes the same bytes. Python 3.13, standard library only, no network access.
